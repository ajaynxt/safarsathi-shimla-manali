# 🏔️ Safar Sathi — Luxury Shimla & Manali Tour & Honeymoon Packages Web Platform

> **Official Reverse-Engineered & Enhanced Travel Web Platform for Safar Sathi (`safarsathi.in`)**  
> Tailored specifically for **Shimla, Kufri, Manali, Solang Valley & Atal Tunnel Tour & Honeymoon Packages**.

---

## 🌟 Overview

`safarsathi-shimla-manali` is a high-converting, modern travel booking web platform engineered with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite 6**. It reverse-engineers and revamps the Safar Sathi travel booking experience with:

- **Interactive Dynamic Price Estimator:** Real-time budget calculator based on duration (3N/4D, 4N/5D, 5N/6D, 6N/7D), pickup city (Delhi/Chandigarh), vehicle tier, and hotel category.
- **Honeymoon Specials Suite:** Dedicated romantic inclusions showcase (Private mountain-view rooms, candlelight dinner, flower bed decoration, celebration cake, wood-fire bonfire).
- **Day-by-Day Route Itinerary:** Comprehensive timeline from Delhi/Chandigarh pickup through Shimla, Kufri, Kullu Valley, Solang Valley, Atal Tunnel, Sissu, and back.
- **Verified Mountain Stays (Lightbox Gallery):** Real hotel & luxury wooden cottage photos from partner properties in Shimla and Manali.
- **100% Dedicated Sanitized Private Cabs:** Transparent fleet choices (Swift Dzire, Maruti Ertiga, Toyota Innova Crysta) with zero hidden driver night charges or toll surprises.
- **Direct 1-Tap WhatsApp Lead Generation:** Every customized package calculation and inquiry routes directly to WhatsApp (`+91 83519 87587`) with pre-filled travel details.
- **Mobile-First Experience:** Sticky call and WhatsApp action bar for instant mobile bookings.

## 💻 Local Development Setup

1. **Clone the repository:**
   \`\`\`bash
   git clone https://github.com/ajaynxt/safarsathi-shimla-manali.git
   cd safarsathi-shimla-manali
   \`\`\`

2. **Install dependencies:**
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the local dev server:**
   \`\`\`bash
   npm run dev
   \`\`\`
   Open `http://localhost:5173/` in your browser.

4. **Build for production:**
   \`\`\`bash
   npm run build
   \`\`\`
